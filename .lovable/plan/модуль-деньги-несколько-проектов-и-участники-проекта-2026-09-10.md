# Модуль «Деньги»: несколько проектов и участники проекта

## Что появится

**Переключатель проектов вверху раздела**
- Строка «Проект: [ Основной проект ▼ ] [+ Новый проект]».
- По умолчанию открывается текущий основной проект.
- Смена проекта полностью переключает контекст: операции, участники, показатели, графики и PDF — только выбранного проекта.

**Создание проекта**
- Кнопка «+ Новый проект» открывает окно: Название проекта*, Заказчик, Объект/адрес.
- Проект создаётся в существующей таблице проектов, получает собственный идентификатор, интерфейс сразу переключается на него.
- Основной проект и его операции остаются без изменений.

**Участники проекта**
- Отдельный блок «Участники проекта» со списком только тех, кто привязан к выбранному проекту.
- «+ Добавить участника»: выбрать из уже существующих или создать нового.
- У каждого — кнопка «Удалить»: убирает участника только из текущего проекта, сам участник и его операции сохраняются.
- Если у участника есть операции в проекте, перед удалением показывается предупреждение: «У участника есть финансовая история в этом проекте. Участник будет исключён из проекта, но его операции и история сохранятся.» с кнопками «Удалить из проекта» / «Отмена».

**Операции и балансы**
- Новые операции записываются с идентификатором выбранного проекта.
- Переводы между участниками остаются внутренними: в истории видны, в доходы/расходы и в остаток проекта не попадают.
- Балансы считаются только по выбранному проекту.

**PDF-отчёт**
- Формируется по выбранному проекту: название, заказчик, объект/адрес, доходы, расходы, остаток, участники и их балансы, отдельный блок внутренних переводов.
- Текущее оформление и цвета отчёта сохраняются.

## Технические детали

- Изменяются: `src/lib/finance-client.ts` (запросы списка проектов, создание проекта, привязка/отвязка участников, выборка участников по `project_participants`), `src/components/admin/MoneyManagerParticipants.tsx` (переключатель, модальные окна, состояние выбранного проекта, ключи кэша по `project_id`), `src/lib/finance-pdf.ts` (объект/адрес и блок переводов), при необходимости `src/lib/finance.functions.ts` для симметрии серверного слоя.
- Новых таблиц и новой базы не создаётся; используются существующие `projects`, `participants`, `project_participants`, `operations`, `categories`.
- Все запросы идут через уже работающий защищённый финансовый relay с текущей авторизацией администратора; сервисные ключи в клиент не попадают.
- Список разрешённых путей relay уже включает нужные таблицы, поэтому доступ не расширяется.

## Проверка

Сборка, открытие основного проекта со старыми операциями, создание нового проекта, изоляция данных между проектами, добавление и удаление участника проекта, сохранность истории, корректность балансов и формирование PDF.
