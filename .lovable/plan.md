# Дополнительные входы в отзывы

## Что изменится
- На главной заменить старый блок отзывов одним блоком существующей клиентской системы сразу после «Наших работ»: до трёх последних опубликованных отзывов, кнопки «Все отзывы» и «Оставить отзыв».
- В этом же блоке добавить компактный призыв «Работали с S&M Electric? Поделитесь впечатлением о нашей работе.» без создания второго списка отзывов.
- Внизу каждой страницы услуги добавить приглашение оставить отзыв.
- В блоке контактов добавить кнопку «Оставить отзыв».
- Все кнопки «Оставить отзыв» будут вести на `/otzyvy?form=1`; существующая страница откроет уже готовую форму автоматически.

## Технические детали
- Использовать существующие `ReviewForm`, `ReviewStars` и `listPublishedReviews`; базу, модерацию и серверную логику не менять.
- Подключить чтение опубликованных отзывов к загрузке главной страницы и показывать только три последних.
- Проверить ссылки, открытие формы без входа, мобильную компоновку и текущую сборку по диагностике проекта.
